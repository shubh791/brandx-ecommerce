 1. EXECUTIVE SUMMARY & BRAND CONTEXT
--------------------------------------------------------------------------------
Brand X is a luxury-tier Indian streetwear and heavy-knit apparel brand operating
both a high-traffic physical flagship store in Samalkha (NH-1, Panipat) and a
scalable direct-to-consumer (D2C) e-commerce web platform.

Core Brand USPs:
- Heavyweight Engineering: 240 GSM single jersey tees up to 450 GSM French Terry hoodies.
- Modern Silhouettes: Drop-shoulder boxy cuts, non-sagging 1.25" collars, 6-pocket parachute cargos.
- Omnichannel Integration: Physical store walk-in trials (08:00 AM - 08:30 PM daily), 30-minute
  in-store click-and-collect pickup, and Pan-India express dispatch (2-3 business days).
- Ultra-Clean Light Aesthetic: International minimalist design matching Snitch, Zara, and Represent.

 3. BACKEND & API ARCHITECTURE SCOPE (NEXT PHASE)
--------------------------------------------------------------------------------

[A] Database Architecture & Schema (Prisma ORM with PostgreSQL):

  1. User Model:
     - id (UUID), name, email, phone, passwordHash, role ("CUSTOMER" | "ADMIN" | "DISPATCHER"),
       addresses (1:N), isVip (Boolean), createdAt, updatedAt.

  2. Product Model:
     - id (String / SKU), name, slug, description, categoryId (FK), price (Int), originalPrice (Int),
       discount (String), gsm (String), fabric (String), fit (String), color (String), colorCode (String),
       tag (String), inStock (Boolean), stockCount (Int), sizes (Array: String), image (String),
       gallery (Array: String), features (Array: String), isActive (Boolean), createdAt.

  3. Order Model:
     - id (String, e.g. "BX-892104"), customerId (FK / Nullable for Guest), guestName, guestPhone,
       guestEmail, shippingAddress (JSON), billingAddress (JSON), subtotal (Int), discount (Int),
       shippingFee (Int), totalAmount (Int), promoCode (String), paymentMethod ("UPI" | "COD" | "CARD"),
       paymentStatus ("PENDING" | "PAID" | "FAILED" | "REFUNDED"),
       fulfillmentStatus ("PLACED" | "CONFIRMED" | "PACKED_AT_HUB" | "DISPATCHED" | "OUT_FOR_DELIVERY" | "DELIVERED" | "CANCELLED"),
       fulfillmentType ("EXPRESS_SHIPPING" | "SAMALKHA_STORE_PICKUP"),
       trackingNumber (String), courierPartner (e.g. "Delhivery" | "Bluedart" | "StoreDesk"),
       estimatedDelivery (DateTime), createdAt, updatedAt.

  4. OrderItem Model:
     - id (UUID), orderId (FK), productId (FK), productName, productImage, selectedSize,
       selectedColor, unitPrice (Int), quantity (Int), total (Int).

  5. TrackingEvent Model:
     - id (UUID), orderId (FK), status, title, description, location (e.g. "Samalkha NH-1 Hub", "Delhi Distribution Center"),
       timestamp (DateTime).

[B] REST & Server-Sent Events (SSE) Endpoints:

  - `POST /api/orders/create`       -> Validate cart, check stock, create order, issue Order ID (#BX-XXXXXX).
  - `GET  /api/orders/[id]`         -> Retrieve order details and current status.
  - `GET  /api/orders/[id]/stream`  -> Server-Sent Events (SSE) endpoint providing live real-time tracking updates.
  - `POST /api/orders/verify-pincode` -> Verify Indian postal pincode delivery SLA.
  - `POST /api/admin/products`      -> Admin CRUD endpoint to add / update / delete catalog items.
  - `GET  /api/admin/orders`        -> List orders with status filters, date ranges, and fulfillment types.
  - `PATCH /api/admin/orders/[id]/status` -> Update fulfillment state and dispatch tracking event.
